# Plantilla semana tipo — Triatlón (genérico, distancia olímpica)

> Stub. Asume 8-10h/semana de entrenamiento, distancia objetivo
> olímpico. Adaptá según tu distancia (sprint = -30%, 70.3 = +50%,
> IM = +100%).

| Día | Mañana | Tarde / Noche |
|-----|--------|----------------|
| Lun | Off o nado técnico 30-40' | — |
| Mar | Bici Z2 60-90' | Run Z2 30' (opcional brick) |
| Mié | Nado intervalos 45' | Strength 30' |
| Jue | Run threshold / intervalos 45-60' | — |
| Vie | Bici tempo 60' | Nado endurance 30-45' |
| Sáb | **Long bike 90-180'** | — |
| Dom | **Long run 60-90'** o brick (bike + run) | — |

**Reglas de la semana:**

- Bricks (bike→run) máx 1-2 / semana.
- Long bike + long run NO el mismo día.
- Si HRV cae > 20% → bajar disciplina con más volumen esa semana.
- Bitácora corporal con hombro / rodilla / tibial open → reemplazar
  esa disciplina por otra.
