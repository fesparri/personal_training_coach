# Plantilla semana tipo — Hipertrofia (Push / Pull / Legs)

> Stub. Asume PPL × 2 (6 días). Adaptalo a tu split preferido (Upper/Lower,
> Full Body 3x, Bro Split 5x, etc.).

| Día | Sesión | Notas |
|-----|--------|-------|
| Lun | Push A (pecho-foco) | Volumen alto pectoral. RIR 1-3. |
| Mar | Pull A (espalda-foco) | Volumen alto dorsal. RIR 1-3. |
| Mié | Legs A (cuádriceps-foco) | Squat, prensa, leg ext. RIR 2-3. |
| Jue | Push B (hombros-foco) | Press militar, lateral, posterior. |
| Vie | Pull B (bíceps + traps) | Remo, curl variado. |
| Sáb | Legs B (isquios-foco) | RDL, curl femoral, glute bridge. |
| Dom | Off | Recovery. Walk Z1 opcional. |

**Reglas de la semana:**

- 1 cardio Z2 30-40' opcional 2x/semana (no afecta hipertrofia, ayuda
  recovery).
- Cada 4-8 semanas: deload (volumen -40%, RIR ≥ 4).
- Si HRV cae > 25% vs baseline 7d → deload anticipado.
- Si sueño < 7h tres días seguidos → reducir RIR target en 1 (más
  conservador) hasta normalizar.
- Bitácora corporal con dolor articular (hombro, codo, rodilla,
  lumbar) → sustituir ejercicio por variante friendly.
